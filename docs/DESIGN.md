# Diary Page Maker — 설계 문서

다꾸용 다이어리 속지를 **4:5 비율**로 만드는 정적 웹앱. 브라우저에서 `index.html` 열기만으로 동작한다.

## 1. 화면 레이아웃

```
+--------------------------------+--------------------------------------+
| 종이정원                       | LIVE PREVIEW                 [4 : 5] |
| 나만의 다이어리 속지 제작소     |                                      |
+--------------------------------+          ┌────────────┐              |
| 오늘은 어떤 종이에              |          │ o          │              |
| 기록하고 싶나요?                |          │ o ──────── │              |
|                                |          │ o ──────── │              |
| 01 무드 고르기                  |          │ o ──────── │              |
| [크림 라인] [세이지 도트]       |          │ o ──────── │              |
| [블러시 체크] [연필 스케치]     |          └────────────┘              |
|                                |                                      |
| 02 내 취향 더하기               | [PNG 크기]        [PNG로 저장하기]   |
| ┌ 종이와 내지 (기본 펼침) ┐     |                                      |
| ├ 여백                  ﹀ ┤     |                                      |
| ├ 종이 모양             ﹀ ┤     |                                      |
| ├ 손그림 감성           ﹀ ┤     |                                      |
| ├ 입체감                ﹀ ┤     |                                      |
| └ 내 스타일 보관함      ﹀ ┘     |                                      |
+--------------------------------+--------------------------------------+
```

- 실제 레이아웃은 2열: **[스타일·세부 조정 패널 | 실물 종이형 미리보기]**
  - 왼쪽 상단의 추천 무드 4종은 배경/내지/외곽/손그림/그림자를 한 번에 적용하는 시작점이다.
  - 자주 쓰는 종이·내지는 기본 노출하고, 여백/종이 모양/손그림/입체감/프리셋은 접이식 카드로 감춰 초기 인지 부담을 줄인다.
  - 프리셋 저장·불러오기·편집·선택 삭제·일괄 PNG·JSON 백업 기능은 미리보기 우측 중앙의 오버레이형 `내 스타일 보관함`에 둔다. 닫힌 상태에서는 세로 탭만 보이고 좁은 화면에서는 하단 시트로 전환되며, 열고 닫아도 미리보기 레이아웃 크기는 바뀌지 않는다. 이름 클릭·체크·드래그 선택은 하나의 선택 상태를 공유하고, 마지막으로 선택한 체크 항목이 불러오기/편집의 현재 항목이 된다. 체크 집합은 선택 삭제와 일괄 PNG의 공통 대상이다.
  - 데스크톱에서는 앱 셸을 뷰포트에 고정하고 `overflow: clip`으로 프로그램식 문서/body 스크롤까지 잠근다. 설정 패널만 독립적으로 스크롤하며, 컨트롤 포커스·SVG 재렌더링에 의한 브라우저 스크롤 앵커 이동을 차단한다.
  - 820px 이하에서는 미리보기를 먼저 보여주고 설정 패널이 아래로 이어지는 세로 레이아웃으로 전환한다.
- 편집기 크롬의 시각 언어는 포트폴리오 사이트(seojin-portfolio)와 맞춘다. 속지 SVG 렌더 결과에는 적용하지 않는다.

  | 토큰 | 값 | 용도 |
  |---|---|---|
  | `--paper` / `--surface` | `#ffffff` / `#f5f7f9` | 패널 배경 / 미리보기 무대 배경 |
  | `--ink` | `#171c24` | 제목, 선택된 세그먼트, 주 버튼, 섹션 상단 구분선 |
  | `--muted` / `--soft` | `#626c79` / `#7a8290` | 보조 문구, 대문자 라벨 |
  | `--line` / `--line-soft` | `#d3d8df` / `#e0e4e9` | 1px 구분선, 입력 테두리 |
  | `--blue` | `#2454d6` | 포인트(활성 상태, 분할 핸들, 셀 선택, 스위치 ON) |

  - 라벨은 10px·650·자간 .1em 이상, 제목은 700·자간 -.055em. 카드 대신 1px 선으로 그룹을 나누고 모서리 곡률은 2px 이하(알약형은 토글·배지·주 버튼만).
- 모든 컨트롤은 `input` 이벤트에서 즉시 미리보기를 다시 그린다 (디바운스 불필요 — SVG 재생성은 저비용)
- 투명 배경 선택 시 미리보기 뒤에 체커보드를 깔아 투명 영역을 표시

## 2. 설정 데이터 모델

단일 상태 객체. 모든 렌더링은 이 객체만 입력으로 받는다.

```ts
interface PageSettings {
  // 배경
  bgColor: string;          // hex, 기본 '#fffaf0'
  bgTransparent: boolean;   // 기본 false — true면 배경 fill 생략(내지 마킹·외곽선만 남음, 그림자도 그 알파에서만)

  // 내지 — 실물 속지 분류대로 한 축으로 통합 (구모델의 배경 패턴 흡수)
  layout: 'full' | 'title' | 'sections' | 'split'; // 페이지 영역 구성, 기본 'title'
  regionTop: RegionElement;    // 기본 'date'
  regionMain: RegionElement;   // 기본 'lined'
  regionSide: RegionElement;   // 기본 'checklist'
  regionBottom: RegionElement; // 기본 'halfRule'
  regionTopRatio: number;      // 상단 높이 비율, 0.08–0.34, 기본 0.16
  regionBottomRatio: number;   // 하단 높이 비율, 0.08–0.30, 기본 0.15
  regionSplitRatio: number;    // 좌우 분할의 왼쪽 비율, 0.28–0.72, 기본 0.57
  regionTopSplitRatio: number; // 섹션 상단의 왼쪽 비율, 0.25–0.75, 기본 0.5
  paper: 'plain' | 'lined' | 'dashed' | 'dots' | 'grid' | 'cross'; // 기본 'lined'
  paperSpacing: number;     // 간격(논리 px), 20–120, 기본 42
  paperWidth: number;       // 선 두께 / 도트 크기 배율, 0.5–6, 기본 1.5
  paperColor: string;       // 기본 '#d5c5b2'
  paperOpacity: number;     // 0.1–1, 기본 0.7

  // 여백 (내지 마킹 없는 영역, 페이지 크기 대비 %)
  // UI: 전체 슬라이더 하나 + '방향별로 다르게' 펼침 (4방향이 다르면 자동으로 펼침 모드)
  marginTop: number;        // 0–25, 기본 6
  marginBottom: number;     // 0–25, 기본 6
  marginLeft: number;       // 0–25, 기본 6 (6공 모드는 최소 96px=12% 강제)
  marginRight: number;      // 0–25, 기본 6

  // 외곽
  punchHoles: boolean;      // 6공 펀칭 on/off, 기본 true
  edgeStyle: 'paper' | 'uniform'; // 종이 단면 그라데이션 / 균일선, 기본 'paper'
  borderWidth: number;      // 0–10, 기본 1.5 — 0이면 외곽선 없음
  cornerRadius: number;     // 0–80, 기본 30
  borderColor: string;      // 기본 '#8b7868'

  // 왜곡 (손그림 효과) — 내지 마킹·외곽선·펀칭 원에 전역 적용
  cartoonAmp: number;       // 강도(진폭 배율), 0–3, 기본 0 — 0이면 반듯
  cartoonSeed: number;      // 패턴(시드 오프셋), 0–99, 기본 0

  // 그림자
  shadowOn: boolean;        // 기본 true
  shadowBlur: number;       // 흐림, 0–30, 기본 12
  shadowOffset: number;     // 거리(dx=dy), 0–20, 기본 5
  shadowOpacity: number;    // 0.05–0.8, 기본 0.2

  // 내보내기
  exportWidth: 1200 | 1600 | 2000;  // 높이 = width × 1.25 (4:5)
}

type RegionElement =
  | 'blank' | 'date'
  | 'lined' | 'dashed' | 'dots' | 'grid' | 'cross'
  | 'checklist' | 'boldRule' | 'halfRule';
```

구모델 프리셋은 로드 시점에 변환한다: `frameStyle` → `punchHoles`+외곽선(v1), `pattern`/`ruling`/`lineStyle`/`borderStyle` → `paper`+`cartoonAmp`(v2, 내지·패턴이 둘 다 있으면 내지 우선, 카툰이 하나라도 있으면 왜곡 켬).

## 3. 렌더링 아키텍처

**핵심 원칙: 미리보기와 PNG 내보내기가 동일한 렌더 함수를 사용한다.**

```ts
// js/render.js — 순수 함수, DOM 접근 없음
function buildPageSvg(settings: PageSettings): string  // 완전한 <svg> 마크업 문자열
```

- 논리 좌표계: `viewBox="0 0 800 1000"` (4:5 고정, 상수 `PAGE_W=800, PAGE_H=1000`)
- 페이지 형태: cornerRadius 적용된 라운드 사각형 path
- 배경/패턴/라인은 페이지 형태로 **clip** — 곡률이 커져도 밖으로 새지 않음
- 페이지 밖 영역과 6공 홀은 **투명** (SVG에 배경 fill 없음 → PNG 투명 유지)

### 요소별 렌더 방식

| 요소 | 방식 |
|---|---|
| 배경색 | 페이지 형태 path fill |
| 페이지 구성 | `gridCols`·`gridRows`를 각각 1~3으로 지정해 최대 3×3 격자를 만든다. 각 셀은 `gridCell0`~`gridCell8`의 요소를 독립적으로 가진다. 미리보기에서 드래그 경로로 지나간 셀 집합을 병합하므로 ㄱ자 등 비직사각형 연결 영역도 가능하며, 기존 병합과 겹쳐 다시 병합하면 기존 그룹의 모든 셀을 흡수한다. `gridMerges`는 셀 인덱스 배열들의 JSON 문자열이고, 비직사각형 영역은 SVG 합집합 clipPath로 렌더한다. 내부 분할선 드래그로 행·열 비율을 조정하며 편집 오버레이는 PNG에 포함되지 않음 |
| 영역별 편집 | 영역을 클릭하면 모달 없이 해당 셀이 활성 영역이 되고 미리보기에서 선택 상태가 유지된다. 왼쪽 편집기의 내선 간격·굵기·색·농도·안쪽 여백은 그 영역에만 적용하며, 요소 선택 모달은 선택 영역 옆 버튼 또는 종이 우측의 플로팅 `요소` 버튼으로 별도 진입한다. 병합 영역은 가장 앞 셀을 대표 키로 사용한다. `areaStyles`는 `gridCellN → 스타일 객체` JSON 문자열이며 설정이 없는 영역은 추천 스타일의 공통 기본값을 상속한다. 종이색·투명도·외곽·펀칭·그림자는 페이지 공통 |
| 미리보기 가이드 | 상단 토글 버튼 또는 `Q` 키로 영역 선택 오버레이·분할 핸들·요소 플로팅 버튼을 함께 숨기거나 표시한다. 입력창·선택창을 조작하거나 모달이 열린 동안에는 단축키를 무시한다. 가이드 UI는 PNG에 포함되지 않는다. |
| 영역 요소 | `renderRegionElement()`가 비우기, 날짜+진한 밑줄, 라인/점선/도트/격자/크로스, 체크리스트, 굵은 전폭선, 반폭 진한선을 렌더. 체크리스트 필기선은 체크박스 아래 변보다 13px 낮춰 글씨와 체크 표시가 시각적으로 분리되게 한다. 둥근 카드 테두리 대신 직선·밑줄·체크박스 등 일반적인 다이어리 문법 사용 |
| 내지 마킹 | `renderPaperMarks()` — 각 영역에서 넘겨준 사각 범위 안에 패턴을 그린다. 6공 모드일 땐 전체 콘텐츠의 왼쪽 최소 여백을 강제해 홀을 회피 |
| 종이 단면 | 두께 0이면 없음. `paper`는 위쪽 반사광과 아래로 짙어지는 단면, `uniform`은 전 둘레 동일 농도의 선. 왜곡 모드에서는 배경과 동일한 지터 path를 단 한 번만 스트로크해 이중선·어긋남 방지 |
| 6공 펀칭 | `<mask>`: 페이지 형태 white + 홀 6개 black → 홀이 투명 컷아웃. 홀 주위 링 스트로크로 펀칭 느낌(왜곡 시 컷아웃과 같은 시드로 핏하게 감쌈). 홀 배치: 왼쪽 x=46, 3개×2그룹 (그룹 중심 y=270 / y=730, 홀 간격 62). 왜곡·외곽선과 독립 토글 |
| 왜곡 (손그림) | `cartoonAmp>0`이면 페이지 형태·내지 마킹·외곽선·펀칭 원이 전부 손그림풍. 페이지: 둘레 점 샘플링 → 법선 방향 **시드 고정** 노이즈 오프셋 → 닫힌 path — **배경/클립/마스크 자체가 이 path를 사용**해 배경이 선 밖으로 안 삐져나옴. 선: 저주파 노이즈 수평/수직 흔들림, 도트/크로스: 위치·크기 지터 |
| 종이 표면 | 배경색 위에 좌상단의 미세한 반사광과 우하단의 아주 옅은 음영을 가진 그라데이션을 겹쳐 완전한 단색 면의 디지털 느낌을 줄임 |
| 그림자 | 하나의 균일한 `feDropShadow` 대신 가장자리 바로 아래의 접촉 그림자, 중간 거리의 주변 그림자, 넓고 옅은 바닥 그림자를 각각 만든 뒤 합성. 페이지 전체 그룹에 적용하므로 펀칭 홀의 투명 컷아웃도 유지 |
| 프리셋 | localStorage(`diaryPageMaker.presets`)에 이름→설정 객체 저장. 로드 시 DEFAULTS와 merge + 구모델 마이그레이션 후 syncControls()로 UI 동기화. 편집은 인라인 편집 모드(2단 컨트롤 재사용, 백업/복원), 일괄 내보내기는 `프리셋이름.png`로 순차 다운로드, JSON 파일로 전체 백업/복원(가져오기 시 충돌 이름은 확인 후 덮어쓰기) |

### 왜곡 지터 (결정적)

- PRNG: mulberry32(고정 시드) — `Math.random()` 사용 금지 (렌더마다 결과가 달라져 미리보기≠출력 문제 발생)
- 페이지 둘레는 ~120 구간 샘플링 + 저주파 노이즈(코사인 보간), 진폭은 borderWidth에 비례(기본 최대 ~4px)
- `cartoonAmp`(진폭 배율 0–3, 0=왜곡 없음)와 `cartoonSeed`(시드 오프셋 0–99, `×7919`을 각 기본 시드에 더함)가 모든 지터에 전역 적용 — 값이 같으면 렌더 결과도 항상 같다(결정성 유지)

## 4. PNG 내보내기 흐름

1. `buildPageSvg(settings)` 로 SVG 문자열 생성 (미리보기와 동일)
2. `Blob` → `URL.createObjectURL` → `<img>` 로드
3. `exportWidth × exportWidth*1.25` 캔버스에 drawImage (배경 fill 안 함 → 투명 유지)
4. `canvas.toBlob('image/png')` → `<a download="diary-page-….png">` 클릭
5. 파일명: `[펀칭_][기본선|카툰선_]{가로칸수}x{세로칸수}_{첫셀요소}.png` — 예: `펀칭_기본선_1x2_날짜.png`

텍스트/외부 이미지/폰트를 쓰지 않으므로 SVG→canvas 래스터화에 CORS·폰트 이슈 없음.

## 5. 파일 구조

```
diary_page_maker/
├── index.html          # 마크업 + 컨트롤 패널
├── css/style.css       # 레이아웃/컨트롤 스타일
├── js/render.js        # buildPageSvg(settings) — 순수 렌더 (미리보기·내보내기 공용)
└── js/main.js          # 상태 관리, 컨트롤 바인딩, 미리보기 갱신, PNG 내보내기
```

- ES 모듈 금지 (`file://` 에서 차단됨) — 일반 `<script src>` 2개, `render.js`가 전역 함수 제공
- 외부 라이브러리 없음

## 6. 구현 단계 (기능 단위 커밋)
